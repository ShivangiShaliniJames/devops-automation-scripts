# DevOps Automation Scripts

This repository contains 3 essential DevOps scripts:

## 1. System Health Check (Bash)

Checks CPU, memory, disk usage and system load.

Run:
bash health_check.sh

---

## 2. Automated Backup Script (Bash)

Creates compressed backups of directories.

Run:
bash backup.sh /path/to/directory

---

## 3. Log Parser (Python)

Parses log files and flags errors and warnings.

Run:
python log_parser.py logs/sample.log

---

## Features

* Lightweight and fast
* Easy to integrate into cron jobs
* Beginner-friendly DevOps utilities
